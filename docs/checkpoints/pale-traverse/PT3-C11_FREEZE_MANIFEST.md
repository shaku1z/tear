engineering slice at implementation identity
`b8ddb454ece2d85f9293134a44e5a7f5aa18df19`. PT3-C0 through PT3-C11 are green

## Frozen shared contracts

- One production stage/boss/enemy/variant authority owns all Pale identities.
- Aurora and Ghost Tracks use the existing bounded environment route runtime.
- Rimehound and White Hart use the existing enemy type/factory composition.
- Pale fields, routes, actors, events, observations, restore documents, and
  hashes use the existing codecs and State Forge boundary.
- Canvas presentation consumes immutable gameplay facts; accessibility changes
  presentation without deleting authored gameplay geometry.
- TearBench routes remain source-derived and fail closed when a production
  identity, scenario, build, or reference projection drifts.

## Owner walkthrough

1. Build with `pnpm build:test:standalone` and serve `dist/test-standalone`.
2. Start Campaign and reach waves 41–50 to see the Pale backdrop, ice
   platforms, Aurora Tracks, native composition, and natural White Hart finale.
3. Use Playground/Enemy Test for Rimehound and each native variant.
4. Use Boss Test for White Hart's three phases, Ghost Tracks, Frozen Wake,
   arena fracture, and Last Crossing.
5. Use the PT3-C3 through C7 artifact folders for exact-source screenshots;
   use PT3-C10 evidence for deterministic scenarios and PT3-C11 for measured
   integrated performance.

## Known limitations

- The seven-stage campaign is engineering-only until separately authorized
  atomic Verdant/Pale integration and protected-main validation.
- Echo/Source relocation, public ruleset/profile migration, bespoke White Hart
  achievements, final music, and cross-repository reference/wiki publication
  remain later integration/release decisions.
- Browser and TearBench output is engineering evidence, not C40 certification.

## Handoff boundary

The next permissible action is a separately authorized joint integration. The
Pale worktree itself requires no further implementation checkpoint. Until that
authorization exists, it remains frozen and must not be pushed, merged,
published, dispatched, deployed, or represented as public campaign authority.
