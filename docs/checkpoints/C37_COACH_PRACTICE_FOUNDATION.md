**Status:** native recorded-observation history is implemented in normal Theater;
built-browser acceptance is pending. The legacy selected-pair analyzer remains a
compatibility API. Challenges, rendered Studio media and inferred skill coaching
are separate open work.

### Preserved v1 foundation

`projectGhostCoachPractice` and `analyzeGhostCoaching` retain their historical
selected-pair APIs, byte/hash meanings and tests. Their legacy fall/blade-event
scalar proxies are not presented as player idle/miss measurements by normal

### Verified Run DNA Theater panel

The normal Theater now has a `RUN DNA` control with a read-only capsule
projection. It calculates `run-dna-v1` only when the verified durable capsule
contains exactly one complete declared `run-dna-metrics-v1` result. The panel
shows that formula version, the capsule custody label, every source metric,
and the five derived dimensions. Missing fields, no declaration, and duplicate
declarations remain visibly unavailable; Theater never substitutes hidden
events, profile/career state, challenge history, exports, or inferred values.

This is a single-run transparent projection, not a career archive, ranking,
recommendation, clustering, challenge, export, persistence, or player-behavior
claim. `tests/unit/ghost-run-dna-theater.test.ts` proves complete-only and
ambiguous/absent refusal; the screen renderer contract retains the semantic
toggle without renderer-owned side effects.

Historical foundation evidence: `tests/unit/ghost-coach-practice.test.ts` covers
v1 distinct-source rejection and same-build provenance. The updated normal
C27/C29 journey exercises the native v2 history and cited prior-checkpoint child;
its new built-browser acceptance remains pending.

### Normal Ghost Lab home

The normal standalone main menu now exposes `GHOST LAB` as a bounded local
home. Academy, Foundry Status, Ghost Vault, local Watch, and read-only Bot
Evidence are normal routes; the Vault remains the existing capsule-gated path
to Theater and Coach. Bot Evidence only asks the immutable C35 evidence vault
for one exact supplied report hash. A missing, stale, or integrity-invalid
report is visibly unavailable; a valid report renders its immutable provenance,
episode distribution, and the explicit `unassigned`, `not compared`, and `not
certified` declarations. It cannot launch evaluation, calculate score or
placement, compare humans, activate/promote a policy, or route traffic. State
Forge, certified Bot Ladder placement, and Studio control remain unavailable.
This creates no cloud, promotion, rollout, or test-query route and does not
claim a forensic developer Ghost Lab.


### Selected local run history (native observations v2)

Normal Theater Coach now lists only capsule metadata until the player explicitly
selects distinct compatible recordings. The open run plus one to seven selected
runs are verified sequentially in one cancellable module worker. Reselection,
closing Coach or leaving Theater terminates that worker; late results cannot
replace the current selection. This path writes no analysis, profile or career
records. Existing v1 analyzer/practice API bytes and hash semantics remain intact;
the normal UI no longer presents their fall/blade-event proxies as idle or misses.

The v2 comparison requires current complete event-bearing profiles and the same
build fingerprint, mode, difficulty, weapon, 120 Hz clock and replay-origin class.
It counts over the explicit shared verified checkpoint interval `(from,to]`,
with `to-from` recorded ticks as denominator. It displays the selected sample
count, min/median/max count distribution and chronological per-exact-measure run
history: identified throws, catches and resolutions, distinct deflected
projectiles, explicit perfect deflections, enemy defeats, waves cleared and void
rescues. Unknown identity/flags make affected measurements unavailable while
retaining known counts and contributing/unclassified event IDs. No guessed alias
correlation, damage/idle/accuracy/skill grade, improvement or human-play claim is
made. Imported/local residence does not establish ownership or authorship. Dates
are recorded metadata, ordered by parsed epoch; different seeds/loadout choices
remain descriptive differences rather than controlled causal comparisons.

The worker preflights at most eight sources, 128 MiB declared decoded data,
64 MiB compressed data and 4096 chunks before reading tracks. These are local
analysis policy bounds, not device memory/performance guarantees. It uses the
existing integrity reader and production replay admission; its verification
means compatible origin/checkpoint continuation, not re-execution of every
intervening causal event. Selected roots/manifests, version and shared interval
bind the output. Source identities are checked again before publishing and before
cited seek/practice. The first 256 target citations are navigable; all measurement
witness IDs remain in the immutable analysis result (details show bounded samples).

View Moment uses the actual verified replay seek, preserving visible refusal.
Full animated V3 world presentation remains a separate dependency. Practice Before
forks the largest verified checkpoint strictly before the cited event, within the
shared window. A same-tick consequence is never substituted. The existing child
launch remains unranked, leaderboard-ineligible and non-persistent; source bytes
are unchanged. The Coach panel exposes selection, measure/history/moment paging,
optional evidence details and close/cancel through normal semantic controls.

Focused controls cover interval boundaries, native coverage, distributions,
epoch ordering, strictly prior checkpoints, identity drift, cancellation and late
results. The existing `browser-ghost-v3-live-capture.js` is authored to generate
actual engineering throw/recall commands, select a three-run cohort, view the
native throw and launch prior-checkpoint Coach practice. Built-browser evidence
for this new history flow is pending parent acceptance. Challenges and rendered
Studio media remain separately open; this feature does not manufacture Run DNA.
