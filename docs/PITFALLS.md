# Tear pitfalls

Things that went wrong, or nearly did, and the rule that came out of each. Every rule
names the check that enforces it. A rule with no automated guard says so; add one when it
is cheap. [AGENTS.md](../AGENTS.md) "Known traps" keeps the short how-to for each.

Add a row when an incident costs real time. Change a row in place when its guard changes.
