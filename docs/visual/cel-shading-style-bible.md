# Superseded combat presentation direction

The cel/anime/comic presentation explored in the first attack-effects slice was rejected after built-browser review because its move-name labels, universal rings, and curved ribbons made Tear look cartoony and physically detached.

The active art and implementation contract is [Grounded combat presentation style bible](grounded-combat-style-bible.md). This file remains only so stale links cannot silently preserve the rejected direction.
