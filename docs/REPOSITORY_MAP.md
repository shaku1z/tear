# Tear repository map

Every top-level entry of the repository: what it is, what writes it, and whether it is
generated. `tests/unit/repository-map.test.mjs` fails when a tracked top-level entry is
missing from the tables below, or when a row names an entry that no longer exists. The
`src/` folders are described in [README.md](../README.md) "Where things live" and
[ARCHITECTURE.md](ARCHITECTURE.md); this page stops at the top level.

"Generated" means a command writes the file and a check compares it; edit the source and
re-run the command instead of editing the output.

## Size caps

Tracked files under `docs/`, `plans/`, `config/`, `preservation/`, `analysis/`, `experiments/`,
`.agents/` and `tests/fixtures/` may not exceed 512 KiB each, except the files listed in
`config/size-caps.json`, each with its own ceiling. `pnpm check:docs` enforces this. Large generated
evidence belongs in `artifacts/` (ignored) with a small tracked digest, as the requirements annex does.
