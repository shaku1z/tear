# Performance and storefront builds: where it stands and what is next

Written 2026-11-21 when the perf session paused for the weekly budget. Goal of the workstream: Tear loads fast and runs smoothly on every storefront and device class with no visual or audio loss, measured and protected by gates. Never raise a budget to pass one; gate files (`config/load-budgets.json`, the code-budget baseline, `scripts/check-bundle-budget.mjs`) need the lead's review.

The measuring tools are in the repository: `pnpm check:load-budgets` (`tests/browser-load-profile.js --check`, ceilings in `config/load-budgets.json`), `pnpm report:load` (every profile; `TEAR_LOAD_TARGETS`, `TEAR_LOAD_PROFILES`, `TEAR_LOAD_REPEATS`, `TEAR_LOAD_OUTPUT`), `scripts/check-bundle-budget.mjs` with `config/bundle-budgets.json`, and the nightly check group. `docs/PERFORMANCE_BUDGETS.md` says what each number means.

## Done

- Startup split: the startup set of the standalone build shrank by moving lazy features behind the shared loader (`src/domain/lazy-module.ts`, `src/app/shell/deferred-modules.ts`) and named chunks (`scripts/application-chunks.mjs`). Tutorial and training code left the startup path (PR 334: 18 startup files, 1,724,262 bytes raw; the gold corpus is fetched with the demonstrations).
- Load profile counts requests to every origin other than the one serving the build (PR 362), with allowed origins and caps per target in `config/load-budgets.json`. Standalone before Firebase slice 2: 5 origins, 4 scripts, 160,421 bytes gzip from gstatic. CrazyGames: the portal SDK only.
- Preview at https://preview.tearblade.com (PRs 365 and 373). The Workers' default Cloudflare subdomains and per-version addresses show the account name, so both are off in both Wrangler configs and a guard test fails on any tracked text holding such an address or the account name. Neither Worker has routes in its file, because Wrangler reads the zone's routes before each deploy once the default subdomain is off and the preview token cannot (run 44913103522). `DEPLOYMENT.md`, Domains, has the re-attach steps.
- Fonts: measured, no change (52,804 bytes, three files, preloaded, off the critical path; removing them did not speed the first frame).
- Firebase slice 2 (PR 371, the modular SDK) measured against main 4f941953: cross-origin scripts 4 / 160,421 bytes to 0, origins 5 to 2, one 66.5 KB gzip same-origin chunk after the first frame, net about 98 KB less over START. First frame unchanged (desktop 406 ms, laptop about 1.07 s in both). Laptop music ready 3,952 ms to 4,376 ms (+10%, ranges overlap): no speedup, possibly slightly slower.
